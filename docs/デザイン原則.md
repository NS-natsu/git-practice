## 1. 配色
- グレースケールで3段階の色を主に使用する。
- RGB指定時は**必ず大文字を使用**する。

| 役割 | 主な用途 | カラーコード |
| :--- | :--- | :---: |
| アクセント(メイン) | テキスト全般、重要な枠線、アイコン | `#252525` |
| 中間色(サブ) | ボタンの背景色、ホバー時の境界線、プレースホルダー | `#D9D9D9` |
| 背景 | 画面全体の背景、カードやコンポーネントの背景 | `#FFFFFF` |

## 2. セレクタの記述ルール

## 2.1. セレクタの記述順序
1つのファイル、または1つのブロック内では、 **広い範囲(ベース)から、狭い範囲(具体的な要素・状態)** へと向かう流れに従ってセレクタを記述する。

1.  **通常セレクタ** (`.counter`, `button` など)
2.  **疑似クラスセレクタ** (`:hover`, `:focus`, `:disabled` など)
3.  **疑似要素セレクタ** (`::before`, `::after` など)

```css
/* ❌ 悪い例：順序がバラバラ */
.button::before { content: ""; }
.button:hover { background: #D9D9D9; }
.button { display: inline-block; }

/* ⭕ 良い例：通常 → 疑似クラス → 疑似要素 */
.button {
  display: inline-block;
  &:hover { background: #D9D9D9; }
  &::before { content: ""; }
}
```

---

### 2.2. プロパティの1ライン記述(特例ルール)
- **原則**: 各プロパティは改行して記述する。
- **指定するプロパティが1つのみ**: コードの見通しを良くするために1ラインで記述してよい。

```css
/* ❌ 悪い例：複数のプロパティを1行で指定 */
.button::before { content: ""; background: #D9D9D9; display: inline-block; }

/* ⭕ 良い例：単一のプロパティの時だけ1行で指定 */
body { inset: 0; }
.button {
  &:hover { background: #D9D9D9; }
  &::before { content: ""; }
}
```

## 3. プロパティの並び順(記述順)
要素内のプロパティは、 **「要素をどこに置くか(外側)」から「要素の中身はどう見えるか(内側)」に向かう同心円の順序** で記述する。

---

### 3.1. 配置・出現情報(Positioning & Display)
要素の「立ち位置」と「表示・非表示」を最優先で定義する。

| 優先度 | 詳細 | プロパティ例(左優先) |
| :--- | :--- | :--- |
| **1** | 要素の性質・レイアウトモードの宣言 | `display` |
| **2** | 基準位置の定義 | `position` |
| **3** | 位置の指定 | `inset` / `top` / `bottom` / `left` / `right` |
| **4** | 重なりの順序 | `z-index` |
| **5** | 表示状態・初期化 | `visibility` / `opacity` / `appearance` |

---

### 3.2. レイアウト・箱のサイズ(Layout & Box Sizing)
親としての並べ方や、要素自身の「箱の大きさ」を定義する。

| 優先度 | 詳細 | プロパティ例(左優先) |
| :--- | :--- | :--- |
| **1** | レイアウト詳細(`display` に従属する設定) | `flex-direction` / `grid-template-*` |
| **2** | 整列・中央寄せなど | `justify-content` / `align-items` |
| **3** | アイテム間の余白 | `gap` |
| **4** | サイズ計算の基準 | `box-sizing` |
| **5** | 横幅 | `width` / `min-width` / `max-width` |
| **6** | 縦幅 | `height` / `min-height` / `max-height` |
| **7** | はみ出しの処理 | `overflow` / `overflow-x` / `overflow-y` |

---

### 3.3. 境界線・外観・余白(Box Model & Background)
箱の周囲のデザインと、外側・内側の余白を定義する。

| 優先度 | 詳細 | プロパティ例(左優先) |
| :--- | :--- | :--- |
| **1** | 外側の余白 | `margin` / `margin-*` |
| **2** | 外側の輪郭線 | `outline` / `outline-*` |
| **3** | 境界線 | `border` / `border-*` |
| **4** | 角丸 | `border-radius` |
| **5** | 内側の余白 | `padding` / `padding-*` |
| **6** | 背景色・背景画像 | `background` / `background-*` |
| **7** | 影 | `box-shadow` |

---

### 3.4. テキスト・その他(Typography & Interaction)
箱の中身(文字・アイコン)の見た目や、アニメーション・インタラクションを定義する。

| 優先度 | 詳細 | プロパティ例(左優先) |
| :--- | :--- | :--- |
| **1** | 文字色 | `color` |
| **2** | フォントの設定 | `font-size` / `font-weight` / `font-*` |
| **3** | 行間・文字間隔 | `line-height` / `letter-spacing` |
| **4** | 文字の揃え方向 | `text-align` |
| **5** | マウス操作の制御 | `pointer-events` / `cursor` |
| **6** | 変形・アニメーション | `transform` / `transition` |

---

## 4. 文字色(color)と currentColor の方針
アイコン(SVGなど)と文字の色を連動させ、CSSの重複管理を防ぐために以下のルールを順守する。

- **ベースの文字色**: 要素(body や各種ブロックなど)の基本となる文字色は、通常通りカラーコード(#252525 など)で直接指定する。
- **子要素・装飾パーツ**: アイコン用のSVGの `fill` や `stroke`、ボタンの `border-color` などで同じ色を使う場合は、直接色を書かずに極力 `currentColor` 等を使用し、親要素の色が変わった際、自動的に連動して色が変わるように設計する。

```css
/* ⭕ 良い例 */
.delete-button {
  color: #252525;
  border: 1px solid currentColor; /* 文字色と連動 */

  &:hover {
    color: #D9D9D9; /* 文字色を変えるだけで、枠線も自動で連動する */
  }
  svg {
    fill: currentColor; /* SVGの色も文字色と連動 */
  }
}
```

## 5. ネスト(CSS Nesting)の運用ルールと階層制限

### 5.1 階層の深さ制限
- ネストの中に構造要素をさらに入れ込むのは、 **元の親要素から数えて最大「3階層(ネストの深さ2)」まで** とする。
- ネストが深くなる場合は、HTMLのクラス設計を見直すか、外に切り出す。

※状態や疑似要素(`&:hover`, `&::placeholder` など)のネストは階層カウントに含めない。
- **1階層目**: `.counter {...}` (親)
- **2階層目**: `  button {...}` (子)
- **3階層目**: `    svg {...}` (孫 ➡️ **ここが上限**)
- **4階層目(例外)**: `    svg { &:hover {...}; }`

---

### 5.2. ネストと分離の境界線
- **ネストで記述してよいもの**: 大枠のコンポーネントに従属し、単体では機能しない単純な要素(`.reset`, `button`, `svg` など)。
- **外に分離して記述すべきもの**: パーツの中にさらに複数の子要素を含み、独自の細かなインタラクション(例: `:focus` 時の背景変化やプレースホルダー制御など)を持つ要素。これらは親のネストから出し、独立したクラス(例: `.counter-title` など)として定義します。

```css
/* ⭕ 良い設計例 */
.counter {
  display: grid;
  /* ...中略... */
  .counter-title { grid-area: /*分離する場合でも、分離元の徹底に依存するものは残す*/; }

  button {
    /* 2階層目 */
    svg { /* 3階層目(上限) */ }
  }
}

/* 独立した子要素や複雑な状態変化を持つため、外に分離して定義 */
.counter-title {
  display: flex;

  > input {
    &:focus { ... }
    &::placeholder { ... }
  }

  > svg { ... }

  &:hover {
    > input { ... }
  }
}
```
